Overview

Stripe Workflows lets you react to payment events with built-in actions. Writeback adds one more: write the result into a system outside Stripe. You pick the trigger, add the Writeback step, map a handful of fields once, and every matching payment updates your form submission, ticket, or endpoint automatically.

Stripe event  →  Workflow runs  →  Writeback step  →  your record updated
(payment succeeded)                  (maps fields)      (JotForm / ServiceNow / REST)

Requirements

  • A Stripe account with access to Stripe Workflows in the Dashboard.
  • For a private install: a team member on your Stripe account with permission to install apps, and the Stripe CLI if you prefer to run the upload yourself.
  • Credentials for the destination: a JotForm API key, a ServiceNow integration user, or the URL of an endpoint that accepts HTTPS POST.

Install

Private install available now

  1. Request early access with a one-line description of what should update when a payment lands.
  2. We schedule one short call to confirm the trigger, the destination, and the field mapping.
  3. The app is uploaded to your Stripe account with stripe apps upload — either by us as a developer on your account, or by you from the bundle we send. Nothing is shared with other accounts.
  4. Writeback appears as an action in your Workflow builder the same day.

Configure the action

  1. In the Stripe Dashboard, open Workflows and create or edit a workflow.
  2. Choose the trigger — for example Payment succeeded, Payment failed, Refund created, or Dispute opened.
  3. Add a step and pick Writeback.
  4. Select the connector and the record to update. For JotForm this is the submission matched by a reference field; for ServiceNow it is the record matched by number or correlation ID; for REST it is whatever your endpoint decides.
  5. Map Stripe fields to destination fields (see the table below). Mapping is saved with the workflow, so it only has to be done once.
  6. Run a test payment in test mode and confirm the destination record changed.

Connectors

JotForm available first

Updates an existing submission. Writeback locates it by the reference you mapped (typically a submission ID carried in Stripe metadata, or an order number field) and writes the mapped values into the fields you choose. Requires a JotForm API key with write access to the form.

ServiceNow next

Updates a record in a table you specify (for example a request, case, or custom billing table) via the Table API. Matched by record number or a correlation-ID field. Requires an integration user with write access to that table.

Any REST endpoint — webhook mode available

Writeback sends an HTTPS POST with a JSON body to the URL you provide. Your endpoint decides what to do with it. Illustrative payload — the final schema is published at Marketplace launch:

POST https://your-endpoint.example.com/writeback
Content-Type: application/json

{
  "event":          "payment.succeeded",
  "status":         "succeeded",
  "amount":         12900,
  "currency":       "usd",
  "receipt_url":    "https://pay.stripe.com/receipts/…",
  "reference":      "pi_3Nxxxxxxxxxxxxx",
  "occurred_at":    "2026-08-26T14:03:11Z",
  "stripe_account": "acct_1xxxxxxxxxxxxx"
}

Respond with any 2xx status to acknowledge. Non-2xx responses are recorded as failures in the run log and retried preview.

Troubleshooting

  • The step ran but nothing changed in my destination. Check the reference mapping first — if the reference value on the payment doesn't match any record, there is nothing to update. Confirm the value is present on the Stripe object (e.g. in metadata) for the test payment.
  • Credential error. The API key or integration user was rotated or lost write permission. Update it in the connector settings; runs that failed in between are not replayed automatically during early access.
  • The action doesn't appear in the Workflow builder. Private installs are per Stripe account and per mode (test / live). Make sure you are in the account and mode the app was uploaded to.
  • I need a field that isn't listed. Email us — additional Stripe fields can usually be added to the mapping the same day.
